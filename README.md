## 📦 Установка Hikka на AWS EC2

### 1. Подготовка сервера и установка

Сначала обновите систему и установите менеджер пакетов для Python

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3-pip -y
```

Затем склонируйте репозиторий, перейдите в папку, установите зависимости и выполните первый запуск

```bash
git clone https://github.com/hikariatama/Hikka
cd Hikka
pip install -r requirements.txt
python3 -m hikka
```

Дождитесь окончания загрузки. Когда процесс остановится, прервите его комбинацией клавиш **CTRL + C**

### 2. Первичная настройка

Запустите бота без веб-интерфейса для базовой конфигурации

```bash
python3 -m hikka --no-web
```

Пройдите процесс авторизации и настройки в терминале. После успешного завершения снова остановите работу через **CTRL + C**

### 3. Запуск в фоновом режиме

Чтобы бот продолжал работать после того, как вы закроете терминал, используйте менеджер сессий `screen`

Создайте новую виртуальную сессию

```bash
screen -S Hikka
```

Запустите бота в фоне

```bash
(python3 -m hikka &)
```

Теперь бот работает автономно и можно радоваться жизни. Если вам когда-нибудь понадобится вернуться в эту сессию (например, для просмотра логов), используйте команду

```bash
screen -r Hikka
```

## 🧩 Установка модулей

### 🔗 Установка по ссылке

Для установки пользовательских модулей отправьте специальную команду прямо в чат Telegram

Используйте базовый синтаксис с прямой ссылкой на код

```text
.dlmod <raw_github_url>
```

**Рабочий пример:**

```text
.dlmod https://raw.githubusercontent.com/akozlovski97/AUTO_Moobot/refs/heads/main/Auto_ControlPanel.py
```

### 📁 Установка модуля из файла

Если скрипт уже скачан на ваше устройство (файл с расширением `.py`), его можно установить локально

**Как это сделать:**
1. Отправьте нужный файл в любой чат Telegram (например, в "Избранное")
2. Сделайте реплай (ответьте) на отправленное сообщение с файлом
3. Напишите и отправьте следующую команду

```text
.lm
```
